# FUTURE_CS_01 - Vulnerability Assessment Report
## Website Tested
demo.testfire.net (Altoro Mutual - intentional security testing demo site)

## Scope
- Read-only, passive analysis only
- No login attempts, exploitation, or destructive testing performed

## Tools Used
- Nmap (port/service scanning)
- Browser DevTools (security header inspection)
- Manual browsing and page source review

## Summary of Findings
7 security issues identified, ranging from Medium to High risk, 
including unencrypted credential transmission, exposed API 
documentation, and missing security headers. Full details and 
remediation steps are in the attached report (PDF).
